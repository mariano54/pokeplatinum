# Map prop models

Every model in `res/field/props/models` (`build_model.narc`), in archive order. Map
JSON files refer to a model by the name in the second column. A prop only renders
if its model is also in the area's prop model set (`res/field/props/model_sets`,
picked by `res/field/area_data`); "Sets" counts how many sets include it.

The internal name is the one Game Freak gave the model. Common parts: `pc` Pokémon
Center, `fs` Poké Mart ("Friendly Shop"), `gym`, `kanban` sign, `door`, `tree`.
`cN_`/`tN_` prefixes mark the city/town a model was made for:

- `c1_`: Jubilife City
- `c2_`: Canalave City
- `c3_`: Oreburgh City
- `c4_`: Eterna City
- `c5_`: Hearthome City
- `c6_`: Pastoria City
- `c7_`: Veilstone City
- `c8_`: Sunyshore City
- `c9_`: Snowpoint City
- `c10_`: Pokemon League
- `c11_`: Fight Area
- `t1_`: Twinleaf Town
- `t2_`: Sandgem Town
- `t3_`: Floaroma Town
- `t4_`: Solaceon Town
- `t5_`: Celestic Town
- `t6_`: Survival Area
- `t7_`: Resort Area

Generated by `tools/scripts/make_prop_model_catalog.py`; see `docs/maps/editing_maps.md`.
